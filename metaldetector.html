Introduction

I led a validation project to determine whether the detection systems in place at a Hill's processing plant could reliably identify heavy-metal contamination — a critical food-safety control point in pet food manufacturing.

Methods

I worked directly with the detection machine's own software to run challenge tests, and used Kneat and SAP to structure the validation protocol, capture results, and maintain cGMP-compliant documentation throughout.

Results

The validation established whether the in-place systems could detect heavy metals at the required sensitivity.

Discussion

Integrating a machine's native software with enterprise quality tools like Kneat and SAP showed me how detection performance and documentation rigor must work together: a system is only as validated as the records that prove it.

My Contributions

  • Led the validation project end to end
  • Operated the detection system software to execute challenge testing
  • Built and maintained the validation documentation in Kneat and SAP
  • Coordinated with plant quality and production staff during testing
