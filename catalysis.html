Introduction

I led a team that developed an AI agent to improve proton-transfer predictions for designing catalysts. The goal was to accelerate catalyst design by letting the agent generate and evaluate candidate structures computationally.

Methods

The team built the agent using LAMMPS for molecular dynamics simulation and UMA, with GitHub for version control and VS Code as our development environment. Team members developed individual modules; my role was ensuring their code integrated into one working pipeline.

Results

The completed agent successfully generated and modeled several catalysts.

Discussion

Leading this project meant less writing code myself and more making other people's code work together — reviewing interfaces, catching integration failures early, and keeping the team aligned through GitHub. Those are the same integration and verification habits that quality engineering demands.

My Contributions

  • Led the project team and set the integration plan
  • Verified that modules written by different team members worked together correctly
  • Managed the shared codebase through GitHub
  • Debugged cross-module failures in the simulation pipeline
